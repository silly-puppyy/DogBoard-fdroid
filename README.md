# DogBoard F-Droid repository

An [F-Droid](https://f-droid.org) repository with the releases of [DogBoard](https://github.com/silly-puppyy/DogBoard),
a private Android keyboard. Add it to the F-Droid app (or Droid-ify, Neo Store) to install DogBoard and get its updates there.

**Repository address:**

```
https://silly-puppyy.github.io/DogBoard-fdroid/repo
```

In F-Droid: Settings › Repositories › **+**, paste the address, and add it. Or open
[this link](https://silly-puppyy.github.io/DogBoard-fdroid/repo?fingerprint=CB8395B4B68B550E93220C23115EDABEEEBF0F191DCADB987CBFAA96EE4FAA83)
on your phone.
